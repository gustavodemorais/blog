Hey, I'm Gustavo de Morais. I'm a Software Engineer at Confluent, building software that lets other people build scalable stream processing applications on cloud-native Apache Flink. I authored the Confluent Cloud Flink SQL Language Server (LSP) and the Flink SQL Shell, and for the past few years I've been contributing to Open Source Apache Flink - things like the MultiJoin operator, `TO_CHANGELOG` and `FROM_CHANGELOG` (Flink's first built-in process table functions), other functions, and various engine optimizations.

I have about 10 years of experience, across a mix of roles: Google Summer of Code student, cofounder, fullstack contractor, and more. In that time I designed, drove, and implemented multiple end-to-end systems for both multinationals and startups, using Java, Kotlin, Go, TypeScript, JavaScript, Kubernetes, Flask, Spring Boot, React, Angular, and Node.js. These days I'm all in on making stream processing with Apache Flink better.
