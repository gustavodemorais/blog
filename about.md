Hey, I'm Gustavo de Morais. I'm a Staff Software Engineer at Confluent, and an Apache Flink committer.

I got into Flink through Google Summer of Code, working on the Hydra smart agent ecosystem back in 2019, and never really left. These days most of my time goes into Flink's Table API and SQL layer - streaming SQL, changelog semantics, process table functions, that kind of thing.

This blog is where I write up the stuff worth a longer explanation than a Slack message or a PR description.
